# Дизайн-скиллы maysoulme

Набор скиллов для Claude Code, на которых собирается весь визуальный контент блога [@maysoulme](https://t.me/maysoulme): карусели для Instagram, гайды-лендинги, презентации к урокам.

Подробное описание и инструкция: **[лендинг-гайд](https://maysoulme.ru/design-skills/)**

## Что внутри

| Скилл | Что делает |
|---|---|
| `skills/carousel.md` | Карусели для Instagram — HTML-слайды 1080×1350, рендер в PNG |
| `skills/guide.md` | Гайды-лендинги и статьи — готовая HTML-страница |
| `skills/presentation.md` | Презентации к видеоурокам (60/40, с местом под спикера) |
| `skills/presentation-full.md` | Полноэкранные презентации с экспортом в PDF |
| `brand/` | Фирменный стиль: style-guide.md + логотипы (образец — замените на свой) |

## Установка (2 минуты)

1. Установите [Claude Code](https://claude.com/claude-code) и Google Chrome (нужен для рендера в PNG/PDF).
2. Откройте терминал и выполните:

```bash
git clone https://github.com/maiyamaiya19999-bit/maysoulme-design-skills.git && cd maysoulme-design-skills && claude "прочитай INSTALL-FOR-CLAUDE.md и выполни установку"
```

3. Claude сам разложит скиллы по местам, всё проверит и покажет отчёт. Дальше в любой папке говорите ему: «сделай карусель на тему…», «оформи этот текст как гайд», «собери презентацию к уроку».

Хотите под свой бренд — скажите Claude: «настрой дизайн-скиллы под мой бренд», он спросит цвет, ник и логотип и всё заменит.
