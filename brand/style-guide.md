# Фирменный стиль maysoulme

## Цвета
- Фон: #ffffff
- Текст: #1a1a1a
- Акцент (бордовый): #710C04
- Серые блоки: #f5f5f5
- Карточки: #f9f9f9, рамка #e8e8e8
- Второстепенный текст: #444, #666, #888

## Шрифты
- Заголовки: Libre Baskerville (serif), жирный + курсив для акцентов
- Текст: Inter (sans-serif), 17px
- Нумерация: Libre Baskerville, курсив, бордовый
- Ник maysoulme: DM Sans (sans-serif), italic, #888

## Правила
- Квадратные углы везде (НЕТ border-radius)
- Серые блоки БЕЗ цветных линий слева
- На тёмном фоне НЕ использовать бордовый (заменять на #c9a07a)
- Навбар: логотип MS слева, курсивный текст maysoulme (DM Sans) справа
