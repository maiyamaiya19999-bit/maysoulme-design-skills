# Скилл: Карусель maysoulme (1080×1350)

Когда пользователь просит сделать карусель — сгенерируй HTML-слайды 1080×1350 в ФИРМЕННОМ стиле (тот же, что гайды/лендинги/презентации) и отрендери в PNG через headless Chrome.

## Дизайн — фирменный стиль, как в гайдах

- Фон белый `#ffffff`, текст `#1a1a1a`, второстепенный `#444`/`#666`
- **Заголовки**: Libre Baskerville 700, 50–58px, курсивные акценты `<em>` бордовым `#710C04`
- **Текст**: Inter, 29px, line-height 1.72
- Серые блоки `#f5f5f5`, квадратные углы, БЕЗ border-radius
- **Навбар на каждом слайде**: логотип MS слева (`logo.png` из `~/Desktop/клод/`, высота 46px) + *maysoulme* справа (DM Sans italic 25px `#888`), линия снизу `#f0f0f0`
- **Футер на каждом слайде**: линия сверху `#f0f0f0`, слева `@maysoulme` (DM Sans italic `#888`), справа *листай →* (Libre Baskerville italic, бордовый); на последнем слайде — *жду в комментариях →*
- Бейдж на обложке: рамка 1px бордовая, капс, letter-spacing 4px («СПОСОБ», «ГАЙД»…)
- Декоративные цифры шагов: Libre Baskerville italic, ~230px, бордовый, opacity .15, абсолютно справа сверху
- Лейблы («ШАГ 1», «ГЛАВНОЕ»): Inter 600, 19px, капс, letter-spacing 4px, `#999`
- Цитаты/промты: серый блок `#f5f5f5` + текст Libre Baskerville italic бордовым
- Фото: «полароид» — белая рамка padding 16px, border `#e8e8e8`, тень, наклон -2°; стикеры PNG поверх с drop-shadow и поворотом
- Скрины: карточка border `#e8e8e8` + padding 16px + лёгкая тень; высокий скрин — контейнер `flex:1 1 0; min-height:0; overflow:hidden` (обрезка снизу)
- Схемки-вариации из скилла презентаций работают и тут: цитата-акцент (кавычка 150px opacity .3 + LB italic 46px), акцентная полоса слева 3px бордовая, команда в рамке бордовой (`/human` + курсор)
- Слова Claude и Reels — всегда латиницей

## Структура типовой карусели

1. Обложка: бейдж + h1 с бордовым `<em>` + подзаголовок + полароид-фото со стикером
2. Крючок/введение
3–5. Шаги: лейбл «ШАГ N» + гигантская цифра + заголовок + текст; скрины по смыслу
6. Перелом «главное»: акцентная полоса слева
7. Результат (команда/формула)
8. Вывод: схемка-цитата
9. Призыв: плашка с кодовым словом (рамка бордовая, letter-spacing 7px) + скрин ТГ-канала (обрезан снизу)

## Рендер

Папка: `~/Desktop/клод/карусели/карусель-<тема>/`. Материалы и `logo.png` скопировать в неё с ASCII-именами.

```bash
for i in 1 2 3 ...; do
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
    --hide-scrollbars --force-device-scale-factor=1 --window-size=1080,1350 \
    --virtual-time-budget=10000 --screenshot="слайд-$i.png" "file://$(pwd)/slide-$i.html"
done
```

ОБЯЗАТЕЛЬНО посмотреть готовые PNG глазами: слайд может отрендериться пустым (перезапустить с sleep 1 между слайдами), футер не должен уезжать за край (`min-height:0` на flex-контейнерах).
