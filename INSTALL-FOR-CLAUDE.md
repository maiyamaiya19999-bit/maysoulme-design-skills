# Установка дизайн-скиллов maysoulme (инструкция для Claude)

Ты выполняешь установку дизайн-скиллов на компьютере участника интенсива Майи (@maysoulme). Пройди пункты по порядку, в конце дай отчёт по каждому. Если какой-то пункт не удался — не молчи и не пропускай: скажи, что именно не вышло, и предложи решение.

## 1. Скиллы

Скопируй все файлы из папки `skills/` этого репозитория в `~/.claude/commands/` (создай папку, если её нет):

- `carousel.md` — карусели для Instagram (1080×1350, PNG)
- `guide.md` — гайды-лендинги и статьи (HTML-страница)
- `presentation.md` — презентации к видеоурокам (60/40, с местом под спикера)
- `presentation-full.md` — полноэкранные презентации с экспортом в PDF

Если в `~/.claude/commands/` уже лежит файл с таким же именем — спроси пользователя, прежде чем перезаписывать.

## 2. Бренд-файлы

- `brand/style-guide.md` → `~/.claude/brand/style-guide.md` (создай папку `~/.claude/brand/`)
- `brand/logo-ms.png` → `~/.claude/brand/logo-ms.png`
- `brand/logo.png` → `~/Desktop/клод/logo.png` (создай папку `~/Desktop/клод/` — скиллы ищут логотип по этому пути)

## 3. Глобальные правила

Создай (или дополни, НЕ затирая существующее) файл `~/.claude/CLAUDE.md` блоком:

```
# Дизайн-скиллы maysoulme

## Фирменный стиль (для всех гайдов, презентаций, каруселей)
- Правила: ~/.claude/brand/style-guide.md — читать перед каждой задачей оформления
- Логотип: ~/Desktop/клод/logo.png
- Ключевое: белый фон, Libre Baskerville (заголовки) + Inter (текст), акцент #6b4f35,
  квадратные углы, �бежевые блоки #f5f0e8; на тёмном фоне коричневый запрещён (заменять на #c9a07a)
- Слова «Claude» и «reels» — всегда латиницей, reels с маленькой буквы
```

## 4. Инструменты

Проверь и при необходимости помоги установить:

- Google Chrome (или Chromium) — нужен для рендера каруселей в PNG и экспорта презентаций в PDF через headless-режим
- `git` — обычно уже есть

## 5. Свой бренд (по желанию пользователя)

Скиллы поставляются со стилем maysoulme как с образцом. Спроси пользователя, хочет ли он адаптировать их под свой бренд. Если да — узнай:

1. Название/ник блога (заменить «maysoulme» в навбарах и футерах)
2. Акцентный цвет (заменить #6b4f35 во всех скиллах и style-guide.md)
3. Логотип (положить свой файл в ~/Desktop/клод/logo.png и ~/.claude/brand/logo-ms.png)
4. Шрифты, если хочется свои (по умолчанию Libre Baskerville + Inter — можно оставить)

Внеси эти замены в `~/.claude/brand/style-guide.md` и во все 4 файла скиллов. Если пользователь пока не готов — оставь как есть, вернуться к этому можно в любой момент фразой «настрой дизайн-скиллы под мой бренд».

## 6. Проверки (выполни реально, не на словах)

1. `ls ~/.claude/commands/` — все 4 скилла на месте
2. `~/Desktop/клод/logo.png` существует
3. Отрендери тестовый HTML в PNG через headless Chrome — рендер работает

## 7. Отчёт

Выведи пользователю таблицу: пункт → статус (готово / ошибка) → комментарий. Если всё готово — предложи проверить в деле: «сделай карусель на тему …» или «оформи этот текст как гайд: …».
